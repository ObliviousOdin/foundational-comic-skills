# Watercolor Storybook Comic

**Style Lock (do not deviate)**

- Soft watercolor washes with bleeding edges
- Whimsical, dreamy atmosphere
- Gentle color blending
- Storybook illustration feel
- Light, airy rendering

## When to Use
- Whimsical, fairy-tale, or gentle stories
- When the reference image supports soft, painterly treatment

## Integration
- Requires `comic-style-memory-system` for watercolor rules
- Works with `comic-long-sequence-orchestrator`

---

*Watercolor treats the page as a painting.*
