# Golden Age Superhero Comic

**Style Lock (do not deviate)**

- Primary color palette
- Ben-Day dot shading
- Heroic, idealized proportions
- Bold, clean linework
- Classic 1940s–50s comic book energy

## When to Use
- Classic superhero or pulp hero stories
- When the reference image supports heroic, iconic treatment

## Integration
- Requires `comic-style-memory-system` for dot and color rules
- Works with `comic-long-sequence-orchestrator`
