# Manhwa Color Webtoon

**Style Lock (do not deviate)**

- Clean digital linework
- Cinematic lighting and color grading
- Vertical scroll-friendly panel flow
- Modern K-drama aesthetic
- High production value rendering

## When to Use
- Modern webtoon-style stories
- When the reference image supports cinematic color treatment

## Integration
- Requires `comic-style-memory-system` for digital rendering rules
- Works with `comic-long-sequence-orchestrator` for serialized webtoons
- **Native format**: `webtoon-scroll-segment` (see `comic-format-library`) via `comic-webtoon-scroll-pipeline` — this style's scroll flow is sanctioned there, not in the 3-panel default

---

*Webtoon treats the scroll as the page.*
