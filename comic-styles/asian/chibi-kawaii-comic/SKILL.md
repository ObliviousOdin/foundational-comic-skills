# Chibi Kawaii Comic

**Style Lock (do not deviate)**

- 2-head body proportions
- Pastel color palette
- Large expressive eyes and simple features
- Emoji-like emotional expressions
- Cute, playful aesthetic

## When to Use
- Light-hearted, cute, or comedic stories
- When the reference image supports exaggerated cuteness

## Integration
- Requires `comic-style-memory-system` for proportion and color rules
- Works well with emotional and slice-of-life stories
