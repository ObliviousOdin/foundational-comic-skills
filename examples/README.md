# Examples

Complete, internally consistent worked projects. Every YAML here is a filled-in instance of a repository template, and every decision traces to a skill.

| Example | Demonstrates |
|---------|--------------|
| `rabot-strip-001/` | The full loop for one 3-panel strip: Producer contract → greenlight → Director shot plan → prompt assembly → final cut with one RETAKE → sign-off. Two characters (Rabot + Echo), so it also demonstrates the relationship cue and multi-character consistency rules. |
| `rabot-4koma-002/` | The same world in a different format: `4koma-vertical` × `kishotenketsu` × `chibi-kawaii-comic`. Demonstrates the bible **delta** pattern (canon referenced, never copied), the reading-direction rule resolved by a vertical format, pacing built from content density because equal panels forbid geometry, and a *ten* beat that shifts perspective instead of landing a punchline. |
| `rabot-webtoon-003/` | The same world, serialized: `webtoon-scroll-segment` × `slow-burn-reveal` × `manhwa-color-webtoon`. The repository's first filled-in **arc ledger**, including a missed emotional target recorded as *arc debt* rather than re-rolled. Also shows the scroll gap as the primary pacing instrument, a reserved colour swatch, and a third registered rendering grammar over one cast. |
| `lamplighter-chapter-001/` | A **cold start** in a new world: `multi-page-chapter` × `painted-prestige-comic`, three scenes composing three different narrative patterns. Shows the **chapter map**, page-turn beats across recto/verso, the single rationed splash, scene-boundary review, and a location registered twice under opposite lighting so the chapter's argument is canon rather than a note. |
| `deskplant-gag-001/` | The smallest format: `single-panel-gag` × `gag-escalation` × `minimalist-line-webcomic`. Shows a pattern whose first two beats are never drawn, the format's one-bubble-**or**-one-caption budget, a shot plan that records which rules are *out of scope*, and the minimum bible that still passes every check. Building it found a contradiction between two styles and the format they both claim. |
| `kell-grid-002/` | The last unbuilt format: `2x2-grid-page` × `parallel-action` × `ligne-claire-franco-belge`, in the Lamplighter world. Shows the **Z-path putting parallel threads on the diagonal**, the T-rule recorded as a Director layout decision, and convergence of meaning without the characters ever meeting. Building it found that *no style claimed this format*. |
| `tidepool-silent-004/` | The first project locking a **pattern** nobody had built: `silent-strip` × `3-panel-horizontal` × `ink-wash-storybook-manga`. Shows **gesture seeding** (the line that would have been, recorded beside the movement that replaces it) and the retake that defines the pattern — an open-mouthed reaction imports speech without drawing a letter. |

**All six sanctioned formats have a worked project, and the first non-default pattern does too.**

Read `rabot-strip-001/WALKTHROUGH.md` first — it narrates the artifacts in order. `rabot-4koma-002/` then shows the deltas rather than repeating the flow, `rabot-webtoon-003/` covers what only a serial can demonstrate, `lamplighter-chapter-001/` builds from nothing in a different world, `deskplant-gag-001/` shows the contract with nowhere to hide, `kell-grid-002/` puts parallel threads on the diagonal, and `tidepool-silent-004/` removes the words entirely.
